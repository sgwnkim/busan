# Workshop Website

## Open locally
Double-click `index.html`, or open it in any modern web browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`.
3. Open Settings → Pages.
4. Select the main branch and save.

## Editing the program
Search inside `index.html` for:
- `Sunday, August 23`
- `Monday, August 24`
- `Tuesday, August 25`
- `Invited Lecture`

You can directly replace times, lecture titles, and speaker names.
